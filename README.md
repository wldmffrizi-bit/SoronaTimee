# SoronaTimee
Soronatime adalah platform web musik digital yang memungkinkan pengguna mengunggah file audio sendiri untuk diputar dan dinikmati. Dilengkapi tampilan modern, pengaturan equalizer (EQ), serta pengalaman mendengarkan musik yang nyaman dengan kualitas suara jernih.  Soronatime — Feel Every Beat, Hear Every Detail.
